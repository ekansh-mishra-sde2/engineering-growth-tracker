# Node js

- Node js is runtime environment for JS to run outside browsers.
- it is built on top of 2 major components
  - The V8 JS engine
  - Libuv library

### Node.js is composed of few dependencies:

- V8
- Libuv
- http-parser
- c-ares
- OpenSSL
- zlib
