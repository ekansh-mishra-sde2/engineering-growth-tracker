## ✍️ How to Add Your Daily Notes

### LeetCode Progress
Edit `logs/leetcode/progress.json`:
```json
{
  "easy": 12,
  "medium": 8,
  "hard": 1,
  "streak_days": 5,
  "last_solved": "Two Sum, Valid Parentheses"
}
```

### Learning Notes
Create a file in `logs/learning/` named `YYYY-MM-DD.md`:
```markdown
## Topic: AWS EC2 & IAM Basics
- Learned difference between IAM roles and IAM users
- Practised launching an EC2 instance with a security group
- Resource: AWS Skill Builder - Cloud Practitioner Essentials
```

The automation takes care of everything else — README updates, weekly summaries, commits.
